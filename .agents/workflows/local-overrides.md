# 宠物学堂 PM 工作流偏好

## 默认启用

- 本项目的需求挖掘、PRD、原型、流程图、验收与数据分析任务默认使用 `edu-pm-workflow`。
- 开始任何产物前，先阅读根目录 `AGENTS.md` 和对应的 `edu-pm-*` 工作流文件，再读取与当前任务直接相关的产品文档。
- 原型视觉与交互必须遵守项目既有儿童安全、家长门、移动端与 iPad 适配约束；Skill 的通用模板不得覆盖项目约束。

## 跨设备约束

- Skill 来源：`https://github.com/beautfulmt/PM-K12--skills`。
- 若设备未安装该 Skill，先提示安装并执行项目初始化；不要依赖某台设备的绝对 Skill 路径。
- `.pm-workflow/` 中的本机凭据、端口和运行状态不得作为可移植配置使用。
