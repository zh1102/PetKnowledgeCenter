# 宠物学堂 MVP 规则冻结清单

> 状态：设计与研发基线 v1.1（2026-09-11）  
> 原则：核心规则与推荐默认值已冻结；数值由后台配置并在每日计划生成时形成不可变快照。

## 1. 已确认且不可偏离

1. 家长闭环：配置学习任务 → 形成今日计划 → 查看提交与确认 → 查看周报 → 调整未来计划。
2. 儿童首次进入：必须先在小猫、小狗、兔子中免费选择一只伙伴；不能跳过，确认后进入今日任务。
3. 今日任务首页为阅读打卡、英语打卡、三米打卡、数学天天练、讲数学题，家长配置与孩子端名称一致。
4. 单项任务完成：只增加今日任务进度，不直接发放星星。
5. 今日礼包：五项任务完成，并且所有需要家长确认的任务均已通过后，才解锁一次今日星星礼包。
6. 礼包只能领取一次；重复点击、网络重试或换设备不得重复发放。
7. 被家长驳回的任务回到待修正，不满足礼包条件。
8. 星星是 MVP 唯一成长货币，用于照料当前宠物；投喂后增加宠物成长值。
9. 宠物阶段固定为哺育期、幼态期、成长期、成熟期，只前进不倒退。
10. 后续可以领养第二只及更多伙伴；每只宠物独立保存阶段、成长值、状态和装扮。
11. 幻想伙伴只允许确定性学习里程碑解锁，不抽卡、不付费、不限时消失。
12. 数学与英语内容默认覆盖中国大众幼小衔接到小学一年级基础/巩固，不默认加入奥数、复杂语法或长篇英文阅读。
13. 讲数学题支持当面讲和录音讲，两种方式均由家长最终确认；系统辅助结果不能直接替代家长确认。

## 2. MVP v1 默认参数

| 参数 | 默认值 | 约束 |
|---|---|---|
| 每日礼包 | 20 颗星 | 后台可设 5–50；生成今日计划时锁定 |
| 每次投喂 | 消耗 5 星、增加 5 成长值 | 每日最多 4 次付费投喂；事务内原子结算 |
| 阶段门槛 | 幼态 50、成长 200、成熟 500 | 每只宠物独立累计，只前进不倒退 |
| 第二只基础伙伴 | 首宠成长期 + 14 个礼包日 | 达标永久保留资格，不扣星星 |
| 第三只基础伙伴 | 已有两只宠物 + 30 个礼包日 | 达标永久保留资格，不扣星星 |
| 幻想小仓鼠 | 30 个礼包日 + 语数英各 5 个确认任务 | 重复练习、取消、驳回不计入 |
| 小青龙 | 60 个礼包日 + 四类学习各 10 个确认任务 | 四类为语文、数学、英语、阅读/表达 |
| 家长确认 | 不超时自动通过 | 可跨日确认；确认后解锁原日期礼包 |
| 礼包有效期 | MVP 不失效 | 每个孩子每个业务日期只领一次 |
| 当日计划修改 | 普通修改次日生效 | 安全下架/家长跳过需审计；已领取后禁止重算 |

## 3. 状态口径

### 3.1 任务实例

`pending → submitted → confirmed`；需要纠错时为 `submitted → rejected → pending`。自动判分任务可由 `submitted` 自动进入 `confirmed`。

### 3.2 今日礼包

`locked → available → claimed`。礼包状态只由服务端依据“必做任务完成 + 必要确认通过”计算；客户端不得自行结算。

### 3.3 宠物

领养关系：`available → adopted`。成长阶段：`nursing → juvenile → growth → mature`。互动失败必须同时回滚星星扣减和成长值增加。

## 4. 研发验收底线

- 同一孩子、同一家庭日期只能有一个今日礼包结算记录。
- 家长不能确认非本家庭孩子的提交。
- 计划版本变更不应篡改已经生成的历史任务。
- 离线只保存提交草稿；星星、礼包和成长必须联网由服务端结算。
- 删除或冻结孩子档案后，所有孩子端写接口拒绝继续变更。
- 所有奖励、领养、互动和阶段变化必须可审计、可幂等重放。
