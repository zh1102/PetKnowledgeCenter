# 宠物学堂 Phase 0.3：描红技术样板验收记录

## 1. 本阶段目标

用一个“永”字验证 uni-app Vue 3 在 H5 与 App-Vue 中的实时描红链路：视图层连续采点，一笔结束后才把归一化笔迹送回逻辑层；刷新或离开页面后可恢复本机草稿。

本阶段不实现书法质量评分、标准笔顺判定、多字课程、云同步或 SQLite 离线队列。

## 2. 完成标准

- 田字格、淡色“永”字字模与实时笔迹稳定显示。
- renderjs 只在一笔结束时回传一次，移动过程不跨层高频通信。
- 坐标保存为 `0~1` 比例值，横竖屏变化后按新画布尺寸重画。
- 轻点、无效坐标、倒序时间、多指或手掌触摸、系统中断不会形成错误笔画。
- 支持撤销、重做和清空；新笔画产生后清空重做栈。
- 草稿包含结构版本、字模标识、字模版本与更新时间；损坏或不匹配的数据拒绝恢复。
- 页面刷新和再次进入可恢复草稿；保存失败时给出可理解提示。
- 桌面、手机横竖屏和平板视口不产生横向溢出，按钮保留稳定点击尺寸。
- H5 和 App 构建均通过。

## 3. 实现位置

- `app/src/components/TracingCanvas.vue`：renderjs 采点、画布绘制、布局变化重绘与逻辑层回传。
- `app/src/features/drawing/model.ts`：笔迹规范化、校验、草稿解析与顺序追加。
- `app/src/pages/tracing/index.vue`：描红页面、撤销/重做/清空、本机恢复与响应式布局。
- `app/tests/drawing.test.ts`：无效输入、坐标边界、草稿损坏与笔画顺序测试。
- `资产/UI/app-tracing-v1/验收`：5 个视口截图和浏览器验收数据。

## 4. 验证结果

### 自动检查

- `npm run check`：通过。
- `vue-tsc --noEmit`：通过。
- Node 测试：19/19 通过，其中描红模型 5/5 通过。
- H5 `uni build`：通过。
- `npm run build:app`：通过，App 产物包含描红页面与 renderjs 代码。

### 浏览器实际交互

- 多指触摸：拒绝生成笔画并显示原因。
- 零长度轻点：拒绝生成笔画。
- 有效触摸：保存第 1 笔。
- 刷新恢复：恢复 1 笔草稿。
- 撤销、重做、清空：状态和画布同步。
- 1024×768、390×844、844×390、768×1024 五组状态/视口：`clientWidth === scrollWidth`，无横向溢出；小尺寸可见按钮数为 0。

## 5. 对抗性审查

- 恶意或损坏输入：限制单笔最多 2048 个点，过滤非数字点并夹紧坐标；拒绝不匹配的结构版本、字模和字模版本。
- 挑剔评审：明确提示该样板不评分；状态反馈可读；禁用不可用操作；截图覆盖空白、已绘制及移动端横竖屏。
- 极端环境：多指和系统触摸中断丢弃未完成笔画；横竖屏切换重建像素缓冲区并按比例重画；存储异常保留当前页面内容并提示。

## 6. 残余风险

- 尚未用物理 iOS/Android 设备验证触控延迟、系统手势冲突、手掌识别和高刷新率帧稳定性。
- 当前使用 `uni storage` 验证中断恢复，不等同于后续 SQLite 离线队列。
- 当前只验证“永”字自由描红，没有标准笔顺、容差轨迹和书写质量算法。
- App 构建已通过，但尚未在 HBuilderX 真机运行产物。
