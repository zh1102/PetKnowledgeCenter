## 1. 基线结论

当前工程是一个可构建的 **uni-app + Vue 3 + TypeScript + Pinia 前端 Mock 原型**，已经覆盖儿童首页、今日任务演示、首次领养、伙伴档案、宠物中心、多宠物里程碑演示，以及三种基础宠物的部分动画。

当前工程不是可生产使用的 MVP：没有账号、服务端、数据库、真实任务内容、跨日账本、家长端、运营后台、离线草稿、录音、描红、内容审核、隐私同意和正式 App 发布配置。所有业务状态在内存中，刷新后重置。

当前项目目录不是 Git 仓库，无法用提交号锁定版本。本阶段使用只读源文件快照压缩包和 SHA-256 清单作为临时回退基线；进入正式开发前仍应创建独立 Git 仓库。

## 4. 已落实的核心业务规则

- 必做任务全部确认后礼包才可领取。
- 礼包重复领取不重复增加余额。
- 系统任务可以自动确认，家长任务必须先提交再确认。
- 投喂扣 5 星、增加 5 成长，每个演示会话最多 4 次。
- 宠物阶段门槛为 50、200、500，只前进不倒退。
- 免费照料只改变对应状态，不增加成长、星星或投喂次数。
- 第二只基础伙伴要求首宠达到成长期且累计 14 个礼包日。
- 第三只基础伙伴要求已有两只且累计 30 个礼包日。
- 三种基础伙伴各限一只，每只伙伴独立保存成长、状态和投喂次数。

这些规则目前只在客户端领域函数和测试中实现。生产环境必须由服务端重新校验并作为唯一事实源。

## 7. 发现的问题与风险排序

### P0：进入正式开发前必须解决

1. **没有独立 Git 仓库**：现有改动无法可靠追踪、审查和回滚。
2. **没有服务端事实源**：星星、礼包日、成长和多宠物资格均可被客户端修改。
3. **没有账号与监护关系**：无法满足儿童数据隔离和家长权限要求。
4. **没有生产 App 配置**：AppID、签名、最低系统版本和真实设备矩阵未确定。

### P1：Phase 0 必须验证

1. 手机与 iPad 全视口布局没有本轮截图验收。
2. 动画没有 iOS/Android 真机性能与后台验证。
3. 录音、音频、描红、SQLite 离线草稿均未实现。
4. 资源目录将历史版本全部打包，存在包体风险。
5. 页面测试缺失，现有 14 项测试只能验证纯领域规则。

### P2：一致性和维护问题

1. 产品设计文档顶部仍写“尚未进入代码实现”，与当前原型事实不一致。
2. 宠物成长路线弹窗仍有“多宠物里程碑领养暂未实现”的过期文案。
3. README 含多轮历史说明，权威状态需要单独索引，避免后文覆盖前文。
4. H5 标题固定为“宠物学堂 · 今日任务”，独立预览页也继承该标题。
