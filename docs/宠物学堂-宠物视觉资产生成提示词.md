# 宠物学堂宠物视觉资产生成提示词

> 版本：v1.0  
> 日期：2026-09-10  
> 用途：生成宠物中心的角色设定、四阶段立绘、动画关键帧、装扮和静态兜底图。  
> 规则：基础伙伴首次免费选择；幻想伙伴由知识能量与学习里程碑确定性解锁；不使用星星购买、抽卡或付费。

## 1. 通用风格锁定词

以下内容追加到每条提示词末尾：

```text
Style/medium: 高质量儿童教育应用二维扁平插画，温柔、童趣、清爽、有秩序；圆润清晰描边，柔和局部阴影，动作容易被3–8岁儿童理解。
Color palette: 淡紫 #EEE9FF、淡黄 #FFF4C7、暖白 #FFFDF7、完成绿 #77BFA3，正文视觉使用柔和深棕或深灰；禁止大面积高饱和色。
Consistency: 严格保持同一宠物在四阶段中的物种识别特征、眼睛颜色、主斑纹、轮廓粗细和基础配色；成长只改变体型比例、特征成熟度和阶段配饰，不改变角色身份。
Background: 真正透明背景，保留完整 Alpha 通道；四周保留安全留白；完整身体不得裁切。
Avoid: 文字、数字、Logo、水印、现有动画或游戏 IP、拓麻歌子设备造型、写实毛发、3D、霓虹、玻璃拟态、武器、战斗、哭泣、生病、受伤、死亡、恐惧、威胁、惩罚、抽卡、金币雨、宝箱和付费暗示。
```

```text
Primary request: 为儿童学习与习惯养成应用“宠物学堂”设计原创{宠物名称}角色设定板。
Subject: {宠物设定}
Composition: 整齐展示正面全身、左侧面全身、背面全身、正面坐姿，以及开心、专注、期待、困倦四种温和表情；另展示核心斑纹或幻想特征的局部细节。各姿态保持完全一致的角色身份，彼此不重叠。
Scene/backdrop: 角色设定板使用纯暖白 #FFFDF7 背景，不添加标题、标签或说明文字。
Constraints: 设定板不是阶段图，仅用于锁定角色身份；完整展示所有主要识别特征。

```

```text
一只原创奶油白小猫，圆形深棕眼睛，淡粉鼻子，额头三道浅淡紫斑纹，尾巴有浅淡紫环形斑纹，黄色星星项圈；头稍大、身体圆润、四肢短小，性格温柔好奇。
```

### 3.2 小狗｜常见伙伴

```text
一只原创奶油杏色垂耳小狗，圆形深棕眼睛，左耳末端有浅淡紫色斑块，短而蓬松的尾巴，黄色星星项圈；身体圆润、爪子短小，性格热情可靠，不使用任何现有犬类动画角色特征。
```

### 3.3 兔子｜常见伙伴

```text
一只原创暖白色垂耳小兔，圆形深棕眼睛，耳朵内侧淡粉，右耳外侧有一小块浅淡紫斑纹，圆形短尾，黄色星星项圈；身体柔软圆润，性格安静细心。
```

### 3.4 幻想小仓鼠｜幻想伙伴

```text
一只原创暖米色幻想小仓鼠，圆形深棕眼睛，浅淡紫色耳缘和背部星点斑纹，脸颊圆润，黄色星星项圈；身边可出现两颗极小的柔和漂浮光点，但不能形成魔法攻击或高刺激特效，性格聪明活泼。
```

### 3.5 小青龙｜幻想伙伴

```text
一只原创儿童友好的小青龙，浅青绿色身体，暖白腹部，浅淡紫色短鬃和尾端，圆形深棕眼睛，两只圆钝软角，四肢短小，黄色星星项圈；无尖牙、利爪、火焰或攻击姿态，性格勇敢温和。
```

## 5. 每阶段动画提示词

动画精灵表必须使用对应阶段标准立绘作为输入参考。每张精灵表保持统一基线、画布和角色中心点；生成后仍需人工切帧和逐帧对齐。

### 5.1 待机动画

```text
Use case: illustration-story
Asset type: {宠物名称}-{阶段}待机动画精灵表
Input image: 对应阶段标准立绘，严格保持角色身份和阶段比例。
Primary request: 生成6个连续待机关键帧，表现轻微呼吸、自然眨眼和该物种特有的柔和尾部或耳部动作。情绪平静、有陪伴感，不催促孩子。
Composition: 横向6帧，每帧尺寸、基线、中心点完全一致，帧间留出均匀透明间隔，不使用分隔线。
[追加通用风格锁定词]
```

### 5.2 获得奖励动画

```text
Use case: illustration-story
Asset type: {宠物名称}-{阶段}学习完成正向反馈精灵表
Input image: 对应阶段标准立绘。
Primary request: 生成8个连续关键帧，从期待、看到一颗淡黄色星星、轻柔开心动作，到最后抱住或触碰星星并温和微笑。动作幅度随阶段变化：哺育期以眼神和前爪回应；幼态期轻跳；成长期挥爪；成熟期点头和纪念动作。
Constraints: 只出现一颗星星，特效仅使用少量淡紫圆点和完成绿小闪光；不得形成金币雨、宝箱或抽奖感。
[追加通用风格锁定词]
```

### 5.3 接受照料动画

```text
Use case: illustration-story
Asset type: {宠物名称}-{阶段}喂食或清洁动画精灵表
Input image: 对应阶段标准立绘。
Primary request: 生成8个连续关键帧，表现宠物看到照料物品、靠近、接受一次轻柔照料、满意回应。哺育期动作最慢；幼态期好奇；成长期主动配合；成熟期从容回应。
Constraints: 不表现饥饿痛苦、狼吞虎咽、脏污羞辱或失败；每组只表现一种照料动作。
[追加通用风格锁定词]
```

### 5.4 阶段成长动画

```text
Use case: illustration-story
Asset type: {宠物名称}从{前一阶段}成长到{后一阶段}的关键帧
Input images: 前一阶段标准立绘作为起点；后一阶段标准立绘作为终点，两者身份必须一致。

Constraints: 不出现破壳痛苦、爆炸、战斗进化、强光闪烁或不可跳过长动画；首尾帧分别严格匹配输入的两个阶段。

```

## 7. 装扮提示词

### 7.1 单件透明素材

```text
Use case: product-mockup
Asset type: 宠物学堂宠物装扮透明素材
Primary request: 绘制一件{装扮名称}，适用于{宠物名称}的{适用阶段}。使用正面三分之二角度，与对应阶段角色的头部、颈部、身体或背部锚点准确匹配。
Style: 与宠物角色完全一致的二维扁平描边和配色，结构简单、儿童友好。
Composition: 只绘制装扮本身，不绘制宠物；四周紧凑留白。
Background: 真正透明 Alpha。
Constraints: 不含属性数字、等级、稀有度、价格和文字；不遮挡眼睛、鼻子、嘴或主要物种特征。
Avoid: 皇冠、武器、盔甲、奢侈品牌、现有IP、过度华丽特效。
```

## 10. 生成与验收顺序

1. 小猫四阶段标准立绘与静态兜底。
2. 小猫四阶段待机、奖励、照料和成长动画。
3. 小狗、兔子角色设定板及四阶段立绘。
4. 幻想小仓鼠、小青龙角色设定板及四阶段立绘。
5. 五只宠物的动画与装扮适配。
6. 未来伙伴占位图。

每张输出检查：角色身份、阶段差异、透明通道、完整身体、画布基线、儿童安全、无文字水印和无第三方 IP。失败输出以新版本文件名保存，不覆盖已通过素材。
