## 核心纵向切片

`家长配置任务 → 孩子首次领养 → 完成自动判分任务 → 提交需确认任务 → 家长确认 → 今日礼包可领取 → 领取星星 → 投喂当前宠物 → 增加成长值 → 达成门槛后进入下一阶段`。

## MVP 外明确不做

排行榜、社交、抽卡、多货币、儿童端付费、宠物交易繁殖、AI 自由聊天、3D/AR 和微服务拆分。
