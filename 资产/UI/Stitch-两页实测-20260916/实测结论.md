## 已验证缺陷

1. Windows 图片上传：插件 assets.py 原本以 os.O_RDONLY 文本模式打开 PNG。参考文件实际 1448694 字节，os.read 仅返回 5 字节，触发 upload file changed while it was being read；失败发生在 HTTP 发送之前。已安装缓存内最小修补为 `os.O_RDONLY | getattr(os, "O_BINARY", 0)`，之后两张图片上传均成功。插件升级或重装可能覆盖该本地修补。
2. 设备：请求 TABLET，1448×1086；get_screen 实测 DESKTOP，2560×2236，不满足设备与同比例整数缩放规则。设备验收失败，不作为 iPad 正式交付。
3. 视觉：诊断截图显示 Logo、导航图标与猫咪被简化重绘；正式宠物插画没有直接复用。导出 HTML 中 img 元素数量为 0。
4. 业务：提示词明确要求将礼包纠正为还差2项，但 HTML 仍出现还差 1 项。3/5 已确认加 1 项待确认、1 项未完成，应剩余 2 项。
5. 可编辑性：HTML 不是整页图片，包含 2 个真实 button；这只证明代码结构存在，不代表业务交互完成。
6. 导出：本地下载 3 个文件并报告 3 个跳过资源警告。HTML 仍引用 Tailwind CDN 与 Google Fonts，离线依赖完整性未通过。
