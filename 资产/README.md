# 宠物学堂资产目录

本目录是项目图片与动效资产的唯一正式存放位置。

## 目录约定

- `宠物/`：宠物角色、成长阶段、装扮、礼包以及对应废弃候选。
- `UI/`：UI 视觉稿、页面参考图、任务图标及设计过程使用的裁切素材。
- `动效/`：宠物序列帧、Lottie、Rive、动效关键帧和降级静态帧。

## 使用规则

1. 后续生成或编辑的图片必须直接保存到对应子目录。
2. 原型和代码使用相对路径引用本目录，不依赖系统临时目录或 Codex 生成缓存。
3. 移动或重命名素材时同步更新引用，并检查不存在缺失图片。
4. `宠物/rejected/` 仅保存未采用候选，不得在正式页面引用。
