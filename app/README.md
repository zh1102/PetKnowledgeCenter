# 宠物学堂 iPad 前端

本地独立工程，uni-app + Vue 3 + TypeScript + Pinia。实现儿童首页、今日任务、首次领养和伙伴详情，复用共享侧栏；今日任务页支持状态筛选。未创建远程仓库。

首次进入会引导猫/狗/兔三选一，填写名字免费领养后进入任务页。投喂消耗 5 星并增加 5 成长，最多 4 次；阶段按 50/200/500 推进并切换正式图片。全部为内存 Mock，仍没有真实跨日计数、服务端账本、装扮与状态衰减。投喂次数对应本次演示会话，不可用于生产日期判断。

领养页现有轻量动效：仅选中伙伴有 4.6 秒周期轻微起伏，切换选择短反馈一次；按钮可暂停，弹窗/提交期间停止，系统 `prefers-reduced-motion` 下禁用。复用静态图片（包含坐垫），不是眨眼、挥爪或真实呼吸动画。浏览器实测初始仅第一只动画，点击暂停后三只及反馈层 computed animationName 均为 none；运行无 error/warn。减少动态效果 CSS 已实现，系统设置和 App 真机未实测。

## 数据与规则

- 本阶段仅内存 mock，刷新重置，无数据库、接口、登录与真实奖励。
- 阅读、英语、三米、讲数学题由家长确认；数学天天练由系统判定。提交任务不发星星，必做任务全部确认后一次领取礼包。
- 35 颗初始星星与 20 颗礼包是演示数据，不是已确定的生产配置。
- 设置入口是开发场景面板：模拟家长确认、离线、下一次失败、空任务和全部待开始。
- 任务内容页暂未开发，任务弹窗明确使用“模拟提交”，不伪装为真实判分。
- 下一阶段可将 store 的异步操作接入接口；生产奖励必须由服务端事务、唯一约束和幂等接口保证，不能信任客户端余额。

多宠物演示已接入宠物中心：首宠成长期且累计 14 个礼包日可免费领养第二只；已有两只且累计 30 个礼包日可免费领养第三只。三种基础伙伴各限一只，切换当前伙伴时各自的成长、状态和投喂次数独立保留。当前工程仍是刷新重置的内存 Mock；可在“今日任务 → 设置 → Mock 场景面板”分别模拟首宠成长期、14/30 个礼包日以检查界面。正式礼包日和领养资格必须由服务端按不同家庭业务日期核验，此演示按钮不产生真实历史记录。

## 验证与交付边界

`npm run check` 执行类型检查、12 项规则测试和 H5 构建。`npm run build:app` 生成 App 资源，需 HBuilderX、真实 AppID、签名和真机测试才能发布；不等于已生成可安装 iOS 包。
